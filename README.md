# 光纖與麥克遜干涉儀互動模擬系統

作者：許翃銨

[開啟互動作品](https://angus931022.github.io/optics-interactive-learning/)

科學視覺化與互動模擬自主學習作品，包含石英與 PMMA 材料切換、波長、長度、溫度及應變控制。

本作品由許翃銨自行規劃主題、整理相關科學概念、設計互動功能並進行整合與測試；開發過程使用生成式 AI 作為程式實作、除錯與修改的輔助工具。作品內容與最終呈現由本人確認與完成。

圖像及動畫供教學示意，未經實驗驗證為定量模型。詳細功能、開發角色與適用範圍見網站 About。

網站採靜態 HTML、CSS、JavaScript 與 Canvas，無需登入或後端資料庫。部署版樣式存於本機檔案，不依賴外部樣式 CDN。
